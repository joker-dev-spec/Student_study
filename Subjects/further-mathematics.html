📐 Vectors

Definition

A vector has magnitude and direction. Vectors are written as column or row forms, e.g. a = (3, 4) or a = 3i + 4j. The dot product (scalar product) of two vectors is a scalar; the cross product (vector product) is a vector.

Dot Product & Magnitude a·b = |a||b| cos θ = x₁x₂ + y₁y₂  |  |a| = √(x² + y²)
Worked Example If a = (2, 3) and b = (4, 1), find a·b.
a·b = (2)(4) + (3)(1) = 8 + 3 = 11
JAMB / WAEC Tip For parallel vectors, a₁/a₂ = b₁/b₂. For perpendicular vectors, a·b = 0. Two vectors are perpendicular if their dot product equals zero.

🔢 Matrices

Definition

A matrix is a rectangular array of numbers arranged in rows and columns. The order (or dimension) is rows × columns. A determinant is a single number calculated from a square matrix.

Determinant & Inverse (2×2) det[a b; c d] = ad − bc
A⁻¹ = (1/det A) × [d −b; −c a]
Worked Example Find the determinant of A = [2 1; 3 4].
det(A) = (2)(4) − (1)(3) = 8 − 3 = 5
JAMB / WAEC Tip Matrices can only be added or subtracted if they have the same order. Multiplication requires that the columns of the first matrix equal the rows of the second. If det = 0, the matrix has no inverse.

📈 Differentiation

Definition

Differentiation finds the rate of change of y with respect to x (dy/dx), also the gradient of the tangent at a point. The chain rule, product rule and quotient rule are used for composite functions.

Power Rule & Chain Rule d/dx(xⁿ) = nxⁿ⁻¹  |  dy/dx = dy/du × du/dx
Worked Example If y = (2x + 1)³, find dy/dx.
Let u = 2x + 1, y = u³. Then du/dx = 2, dy/du = 3u².
dy/dx = 3u² × 2 = 6(2x + 1)² = 6(2x+1)²
JAMB / WAEC Tip Gradient of y = f(x) at x = a is found by substituting x = a into dy/dx. Maximum and minimum points occur where dy/dx = 0.

∫ Integration

Definition

Integration is the reverse of differentiation. Indefinite integration adds a constant C; definite integration between limits gives a numerical area under a curve.

Integration Rules ∫xⁿ dx = xⁿ⁺¹/(n+1) + C  |  ∫ₐᵇ f(x)dx = F(b) − F(a)
Worked Example Evaluate ∫₀² 4x dx.
∫4x dx = 2x²
= 2(2²) − 2(0²) = 8
JAMB / WAEC Tip Remember +C for indefinite integrals but NOT for definite integrals (the constant cancels). Area under the graph = definite integral (take absolute value if the curve dips below the x-axis).

🎲 Probability

Definition

Probability measures the likelihood of an event occurring, ranging from 0 (impossible) to 1 (certain). P(A) = number of favourable outcomes / total number of possible outcomes.

Probability Rules P(A) = favourable / total
P(A∩B) = P(A) × P(B)  (independent)
P(A∪B) = P(A) + P(B) − P(A∩B)
Worked Example Two fair dice are thrown. Find P(sum = 7).
Favourable: (1,6)(2,5)(3,4)(4,3)(5,2)(6,1) = 6 outcomes.
Total = 36.
P = 6/36 = 1/6
JAMB / WAEC Tip P(not A) = 1 − P(A). For independent events, the occurrence of one does not affect the other. Mutually exclusive events: P(A∩B) = 0, so P(A∪B) = P(A) + P(B).
