🖥️ Hardware & Software

Definition

Hardware refers to the physical components of a computer that you can touch. Software is a set of instructions (programs) that tells the hardware what to do.

Hardware Components

  • CPU (Central Processing Unit): the "brain" — executes instructions and processes data.
  • RAM (Random Access Memory): volatile, temporary storage for active data.
  • ROM (Read-Only Memory): non-volatile; stores boot-up instructions.
  • Storage: Hard disk, SSD, flash drive — permanent data storage.
  • Input devices: keyboard, mouse, scanner, microphone.
  • Output devices: monitor, printer, speaker.

Software Types

  • System software: Operating System (Windows, Linux, macOS) — manages hardware.
  • Application software: Word, Chrome, games — end-user programs.
WAEC Tip 1 KB = 1024 bytes, 1 MB = 1024 KB, 1 GB = 1024 MB. RAM is volatile (data lost on power off); ROM and hard disks are non-volatile. The CPU contains the ALU (arithmetic/logic) and control unit.

💻 Programming

Definition

Programming is writing step-by-step instructions (code) in a language a computer can understand to solve problems. Examples of languages: Python, Java, C++, JavaScript, BASIC.

Programming Concepts

  • Algorithm: a step-by-step procedure for solving a problem.
  • Variable: a named storage location that holds a changeable value.
  • Sequence: instructions executed one after another in order.
  • Selection (branching): IF-THEN-ELSE makes decisions.
  • Iteration (looping): FOR and WHILE repeat instructions.
  • Bug: an error in a program. Debugging: finding and fixing bugs.

Steps in Program Development

  1. Define the problem
  2. Design the solution (algorithm / flowchart)
  3. Write the code
  4. Test and debug
  5. Maintain / document
WAEC Tip Know the difference between high-level languages (Python, BASIC — easier for humans) and low-level languages (machine code — easier for computers). Pseudocode and flowcharts are used to design algorithms before coding.

🌐 Networking

Definition

A computer network is a group of connected computers that share resources and information. Networks are classified by size: LAN (Local Area Network), WAN (Wide Area Network), MAN (Metropolitan Area Network).

Key Networking Concepts

  • LAN: connects devices in a limited area (school, office).
  • WAN: connects networks over large distances (the Internet is a WAN).
  • Router: directs data between different networks.
  • Switch/Hub: connects devices within the same network.
  • Protocols: HTTP (web), FTP (file transfer), SMTP (email).
WAEC Tip Advantages of networks: resource sharing, communication, data sharing. Disadvantages: security risks, virus spread, cost of setup. Remember: Internet = Interconnected Network of Networks; WWW = World Wide Web.

🔢 Data Representation

Definition

Computers store all data in binary (base 2), using only the digits 0 and 1. Each binary digit is a bit; 8 bits make a byte.

Number Systems

  • Binary (base 2): digits 0–1. Place values: 1, 2, 4, 8, 16...
  • Decimal (base 10): digits 0–9.
  • Hexadecimal (base 16): digits 0–9, A–F. A=10, B=11... F=15.
Binary → Decimal 1010 = 1×8 + 0×4 + 1×2 + 0×1 = 10
Worked Example Convert the decimal number 15 to binary.
15 ÷ 2 = 7 r 1
7 ÷ 2 = 3 r 1
3 ÷ 2 = 1 r 1
1 ÷ 2 = 0 r 1
Reading remainders upward: 1111
WAEC Tip Hexadecimal is used as a compact way to represent binary: each hex digit = 4 binary digits. 1 byte (8 bits) = 2 hex digits. Common conversions to memorise: 10 = A, 15 = F, 16 = 10 in hex.
